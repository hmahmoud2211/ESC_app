# Deployment Instructions

The ESC Activewear project is configured for deployment on Netlify. We've already prepared the project with:

1. A successfully built application in the `build` directory
2. A properly configured `netlify.toml` file pointing to the correct build directory
3. All necessary assets and dependencies

## Manual Deployment Steps

### Option 1: Deploy via Netlify UI

1. Log in to your Netlify account
2. Click on "Add new site" > "Import an existing project"
3. Choose "Deploy manually" option
4. Drag and drop the following files/directories from this project:
   - `build` directory
   - `netlify.toml` file
   - `package.json` file
   - `public` directory

### Option 2: Deploy via Netlify CLI

If you have Netlify CLI installed:

```bash
# Install Netlify CLI if you don't have it
npm install -g netlify-cli

# Log in to your Netlify account
netlify login

# Navigate to the project directory
cd /path/to/app-landing-clone

# Deploy the site
netlify deploy --prod
```

### Option 3: Connect to GitHub Repository

1. Push this project to a GitHub repository
2. In Netlify, click "Add new site" > "Import an existing project"
3. Choose GitHub as the Git provider
4. Select your repository
5. Netlify will automatically detect the build settings from the netlify.toml file
6. Click "Deploy site"

## Troubleshooting

If you encounter any issues during deployment:

1. Make sure the `build` directory contains all the files generated by `next build`
2. Verify that the `netlify.toml` file has the correct `publish` directory set to `build`
3. Check that the `@netlify/plugin-nextjs` plugin is included in the netlify.toml file
